# Шаблон записи кодекса

**Status:** Approved · **Version:** 0.1 · **Last Updated:** 6 сентября 2026.

Карточка — максимум 10 строк. Лор — 1–2 строки, не рассказ. Чисел нет (ссылка на `Balance/`), механик нет (ссылка на `Systems/`). Новая сущность в игре — новая карточка + строка баланса, иначе её не существует.

## Моб

**Имя (slug)** — роль одной строкой.
- Образ: 1–2 строки.
- Поведение: агрессивный/мирный, одиночка/стая, скорость, дальность.
- Где найти: зона и места.
- С чем связан: репутация, квест, рецепт, чемпион.
- Лут: кратко + ссылка на баланс.

## Предмет (полная карточка — только ключевым)

**Имя (slug)** — что это.
- Образ: 1 строка.
- Применение: надеть / использовать / материал / трофей.
- Откуда: магазин / крафт / лут / квест.
- Статус: магазин / крафт / лут (по правилу).

## Класс

**Имя** — фэнтези одной строкой.
- Роль: в соло и в группе.
- Стартовые скиллы + путь обучения (ссылка на баланс цен).
- За счёт чего растёт (ссылки на формулы в балансе).

## Скилл

**Имя (slug)** — что делает, когда брать, с чем сочетается. Цены — ссылкой на баланс.
