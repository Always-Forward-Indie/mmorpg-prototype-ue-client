## TL;DR

Проверяем две сессии: боевую (воин/маг, Альфа) и мирную (руда → изделие → продажа). Смотрим поведение, а не слушаем похвалу. Маленькую группу показываем абсолютными числами со знаменателями.

## Кого зовём

Бойцы и мирные игроки отдельно; форматы: соло, вдвоём, группа 2–5. Первая сессия и повторная — обязательно обе.

## Сценарии

**A. Боевой:** старт → поляна (обычный бой) → лес → Альфа (если созрел) → дележ.
**B. Мирный:** руины (история, мирным путём — скелетов можно обойти/переждать; если обхода нет — фиксируем как блокер) → точки добычи → станция (изделие) → использование/продажа. Обязательный peaceful flow должен быть реально проходим без убийств.
Ничего не подсказывать. Фиксировать, где застряли.

## Гипотезы и критерии

| Гипотеза | Наблюдаем | Спрашиваем | Успех |
|---|---|---|---|
| Бой приятен сам по себе | Повтор боя без цели | «Чем отличаются классы?» | Называют разные решения, повторяют бой |
| Лут значим | Смена экипировки, план охоты | «Что запомнилось из находок?» | Помнят предмет и объясняют зачем он |
| Мир тянет исследовать | Сход с маршрута по своей воле | «Куда бы пошёл дальше?» | Называют свой следующий план |
| Помощь возникает сама | Помощь, инвайты, обмен | «Было ли понятно с наградой?» | Совместные сессии без просьбы |
| Свой темп | Короткая vs длинная, возврат после перерыва | «Что делать дальше?» | Цель понятна, «догонять» не надо |
| Мирная сессия полна | Прохождение без убийств | «Что сделал с изделием?» | Результат: вещь, продажа, заказ |

## Правила

- Вопросы нейтральные: «Что запомнилось?», «Когда захотелось закончить?», «Что дальше?»
- Не подсказывать ответы про лут и дружелюбие — это исказит проверку.
- Числовых целей удержания не ставим: маленькая выборка их не даёт.
- После теста: что услышали → что проверили → что изменили или отложили. Решения — строкой в Decision_Log.

## Инструментация наблюдений (не метрики)

Фиксировать события сессии как факты поведения (не CTR): старт/конец сессии → визиты зон → повторы боя → добыча → изучение рецепта → изготовление → торговля → помощь/группа → возврат. Память тестировщика дополняется, не заменяется.

## Решение после теста

Пройден, если выполнены критерии успеха слайса (см. `Stage_1_Vertical_Slice.md`). Иначе — правим препятствия (управление, награды, маршрут) и повторяем, а не добавляем системы.
